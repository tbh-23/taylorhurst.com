🏡 Homestead

A mastery-based homeschool platform for ages 5–13.

  • Turns an open, connected curriculum of ~1,590 micro-topics into a clear learning path — every idea mastered (90%+) before the next begins.
  • Personalized AI tutoring: lessons, tests and remediation shaped to how each child learns.
  • Built on learning science — mastery learning, active recall, spaced practice — with the receipts cited.
  • Installable PWA, works offline, year-end printable reports.

Stack: vanilla JS + HTML/CSS, Puter.js for auth/storage/AI, no build step.
