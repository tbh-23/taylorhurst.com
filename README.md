# taylorhurst.com

My personal site: a little retro desktop OS whose alpenglow sky follows Denver's time and weather.

Everything lives in `index.html` (no build step).

## Updating

1. Edit `index.html`
2. Commit and push to `main`
3. GitHub Pages republishes in about a minute

Handy spots inside `index.html`:

- **Races**: the `RACES` list. Each race has a date and flips from upcoming to past on its own.
- **Flights**: the `FLIGHTS` list (`["year","FROM","TO"]`). Add new airports to `AIRPORTS`.
- **Writing**: the `ESSAYS` list.
